# Demo Checklist

1. Start the app with the `city_airline_client` account, not root.
2. Search for a flight by airport and date.
3. Select a flight and show the joined flight details.
4. Show the seat-class availability summary.
5. Run the Fare Deals report and explain its minimum, maximum, and average prices.
6. Create a passenger profile and update a passenger contact record.
7. Purchase an available ticket and show the success message.
8. In Demonstrations, run the below-average flight report and explain its subquery.
9. Purchase an available ticket to show COMMIT, then run the rollback test and show that the temporary passenger was not saved.
10. Run the duplicate-ticket constraint demonstration.
11. Run the denied flight-creation demonstration.
12. Point to `%s` placeholders in `app/data.py` when discussing parameterized input.
